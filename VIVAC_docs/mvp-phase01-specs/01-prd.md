## 2. 배경 및 문제 정의

### 2.1 시장 배경
국내 백패킹/캠핑 인구는 지속 성장 중이며, 특히 BPL(Backpacking Light)/UL(Ultralight) 커뮤니티는 20-30대를 중심으로 빠르게 확장되고 있다. 그러나 이들이 활용할 수 있는 야영 장소 정보는 다음과 같이 분산되어 있다:

- **한국관광공사 GoCamping API**: 등록 캠핑장 정보
- **산림청 API**: 휴양림, 자연휴양림 정보
- **국립공원공단 API**: 국립공원 내 야영장 정보

### 2.2 문제 정의
1. **정보 분산 문제**: 사용자가 원하는 장소를 찾기 위해 여러 사이트/앱을 순회해야 함
2. **타깃 적합성 문제**: 기존 서비스(고캠핑, 캠핏 등)는 일반 캠핑 사용자 중심이며, BPL/UL 백패커의 니즈(도보 진입, 노지, 경량 등)에 특화되지 않음
3. **데이터 부재 문제**: 백패커 커뮤니티의 실제 선호도/행동 데이터가 시장에 존재하지 않아, 맞춤 서비스 개발이 어려움

### 2.3 경쟁 서비스 분석
| 서비스 | 특징 | 한계 |
|---|---|---|
| 고캠핑 | 한국관광공사 공식, 정보량 많음 | UI/UX 노후, 일반 캠핑 중심 |
| 캠핏 | 예약 통합, 모바일 친화 | 등록 캠핑장 위주, 백패킹 부적합 |
| 올트레일 | 트래킹 코스 중심 | 야영 정보 부재 |

## 3. 비전 및 목표

### 3.1 비전
> **"국내 BPL/UL 백패커가 가장 먼저 찾는 야영 장소 디스커버리 플랫폼"**

### 3.2 장기 목표 (12개월+)
- 국내 BPL/UL 커뮤니티의 사실상 표준 도구로 자리잡음
- 사용자 행동 데이터 기반의 개인화 추천 엔진 구축
- 프리미엄 구독(VIVAC Pro), C2C 중고장터, B2B 데이터 라이선싱으로 수익 다각화

### 3.3 Phase-1 단기 목표
1. **빠른 MVP 출시 및 초기 유저 확보**
2. **온보딩 설문을 통한 초기 사용자 세그먼트 데이터 확보**
3. **베타 테스트 가능한 수준의 기본 디스커버리 경험 제공**

## 4. 타깃 사용자

### 4.1 Primary Persona — BPL/UL 백패커

| 항목 | 내용 |
|---|---|
| 연령 | 20대 후반 ~ 30대 후반 |
| 성별 | 남녀 모두 (남성 비중 다소 높음) |
| 활동 빈도 | 월 1~3회 |
| 주요 니즈 | 도보 진입 가능한 노지/계곡, 경량 패킹 적합 장소, 사진 촬영 좋은 풍경 |
| 의사결정 요소 | 위치, 풍경 사진, 차량 진입 여부, 무료 여부, 시설 유무 |
| 정보 수집 채널 | 인스타그램, 유튜브, 블로그, 카페 커뮤니티 |

### 4.2 Secondary Persona — 백패킹 입문자
- 20-30대, 백패킹에 관심 있으나 경험 부족
- 정보 진입장벽이 높아 시작을 어려워함
- 안전하고 접근성 좋은 장소 정보 필요

## 7. 검증 가설

### H1. 통합 데이터 가치 가설
> BPL/UL 백패커는 분산된 공공 API 데이터를 단일 인터페이스에서 탐색할 수 있을 때, 기존 대비 짧은 시간에 의사결정을 내린다.

**검증 지표**: 검색→상세 진입 전환율, 평균 세션 길이, 세션당 검색 수
**성공 기준**: 검색→상세 진입 전환율 30% 이상

---

### H2. 세그먼트 데이터 가치 가설
> 5단계 온보딩 설문을 통해 향후 추천 알고리즘 및 마케팅에 활용 가능한 의미있는 사용자 세그먼트를 확보할 수 있다.

**검증 지표**: 온보딩 완료율, 세그먼트 분포의 다양성, 단계별 이탈률
**성공 기준**:
- 온보딩 완료율 70% 이상
- 5개 주요 세그먼트(스타일×환경 조합)에 사용자 균등 분포

---

### H3. 카테고리 필터 선호도 가설
> BPL/UL 백패커는 자유 텍스트 검색보다 카테고리 빠른 필터를 더 선호한다.

**검증 지표**: `category_filter_clicked` vs `search_executed` 사용 비율
**성공 기준**: 카테고리 필터 사용 비율이 검색 대비 1.5배 이상
**활용**: 향후 정렬·필터 UI 우선순위 결정 근거

## 9. 핵심 정책

### 9.1 Soft Wall + Value Lock 정책

#### 9.1.1 정책 개요
첫 진입 이탈률을 최소화하면서, 가입과 온보딩 완료의 명확한 가치 제안을 유지하는 하이브리드 전략.

#### 9.1.2 Free Tier (비가입자)
- 홈 화면 전체 탐색 가능
- 검색 / 카테고리 필터 / 일반 필터 사용 가능
- 큐레이션 섹션 열람 가능
- 검색 결과 카드 열람 가능
- 상세페이지 진입 및 Tier 1 정보 열람 가능
- 🔒 **상세페이지 Tier 2 정보 락** (블러 처리)
- 🔒 **예약/외부 링크 CTA 락**

#### 9.1.3 Member Tier (가입 + 온보딩 완료)
- Free Tier의 모든 기능 + 락 해제
- "OO님을 위한 추천" 라벨링 (개인화 시각 표시)
- 온보딩 답변 기반 시각적 강조 (선호 환경 등)

#### 9.1.4 락 트리거 동작
| 액션 | 동작 |
|---|---|
| 락된 영역 클릭 | 바텀시트 모달 노출 |
| 모달 카피 | "더 자세한 정보를 보려면 가입 후 내 취향을 알려주세요" |
| CTA | "가입하고 확인하기" + "닫기" |
| 닫기 | 항상 가능 (강제 아님) |
| 노출 빈도 | 동일 페이지에서 1회만 (sessionStorage) |

#### 9.1.5 로그인 후 리다이렉트 보장
- `?redirect=` 쿼리 파라미터 + sessionStorage 백업
- URL state 우선 활용 (검색어, 필터, 카테고리 상태 유지)
- 외부 도메인 redirect 차단 (보안)
- 같은 도메인 내 비허용 경로 차단 (화이트리스트 검증)
- 온보딩 미완료 시: 로그인 직후 자동으로 온보딩 진입
- 온보딩 완료 후: redirect 파라미터 우선 → 없으면 홈

### 9.2 데이터 정책
- **이미지 호스팅**: Phase-1은 공공 API 원본 URL pass-through, Phase-2 이후 자체 스토리지 전환 검토
- **이미지 부재 시**: 노출 + 플레이스홀더 (BI 일러스트 활용)
- **이미지 저작권**: 공공 API 사용 약관 준수, 출처 표기 검토
- **큐레이션**: 수동 큐레이션 (DB 테이블 또는 환경변수)
- **운영 상태**: ETL 단계에서 운영중 장소만 검색 결과에 노출 (폐업/휴무 제외)

### 9.3 카테고리 매핑 정책
| 카테고리 | Phase-1 처리 |
|---|---|
| 계곡, 바다, 산·숲, 강·호수 | `features` 기반 구현 |
| 노지 | 백엔드 협의 후 구현 |
| 국립공원 | 백엔드 협의 후 구현 |
| 차박 | Phase-1 제외 |

## 13. 리스크 및 가정

### 13.1 가정 (Assumptions)
- 공공 API의 안정성과 데이터 품질이 일정 수준 이상이다
- BPL/UL 커뮤니티가 "통합 디스커버리" 가치에 반응한다
- 모바일 PWA가 RN 앱 대비 충분한 사용성을 제공한다
- 구글 소셜 로그인이 타깃 사용자에게 익숙하다

### 13.2 리스크 (Risks)

| 리스크 | 영향도 | 대응 방안 |
|---|---|---|
| 공공 API 데이터 품질 미달 (사진 부재, 누락 필드) | 🔴 높음 | 플레이스홀더 처리, F4(데이터 품질 관리) 우선순위 상향 |
| Hard Wall에 가까운 정책으로 이탈률 높음 | 🟡 중간 | Value Lock 정책으로 완화, 깔때기 트래킹으로 조기 감지 |
| 온보딩 5단계가 너무 길어 이탈 | 🟡 중간 | 단계별 건너뛰기, 카피 프레이밍, 진행률 표시 |
| 평점/리뷰 부재로 신뢰도 낮음 | 🟡 중간 | Phase-2 이후 리뷰 시스템 우선 추가 |
| 큐레이션 운영 부담 | 🟢 낮음 | 초기 10-20개 수동 큐레이션, 점진적 자동화 |
| 차박/노지/국립공원 카테고리 매핑 실패 | 🟢 낮음 | 매핑 가능한 카테고리만 우선 노출 |

## 14. 부록: 용어 정의

| 용어 | 정의 |
|---|---|
| **BPL** | Backpacking Light. 경량 백패킹 |
| **UL** | Ultralight. 초경량 백패킹 (배낭 무게 ~5kg 이하 지향) |
| **노지** | 지정된 캠핑장이 아닌 자연 그대로의 야영 가능 장소 |
| **비박** | 텐트 없이 자연에서 하룻밤 보내는 행위 |
| **차박** | 차량을 베이스로 한 캠핑 |
| **Soft Wall** | 비가입자도 일부 기능을 사용할 수 있게 하는 정책 |
| **Hard Wall** | 가입 전에는 어떠한 기능도 사용할 수 없게 하는 정책 |
| **Value Lock** | 핵심 가치 영역에 락을 적용해 가입 동기를 유발하는 전략 |
| **Free Tier** | 비가입자에게 제공되는 기능 범위 |
| **Member Tier** | 가입+온보딩 완료자에게 제공되는 기능 범위 |
| **Tier 1/2/3** | 상세페이지 정보의 우선순위 분류 |
| **F1~F5** | MVP 핵심 기능 5종 (검색·필터·북마크·품질관리·온보딩) |
| **PWA** | Progressive Web App. 웹 기반 앱 경험 제공 기술 |
| **ETL** | Extract, Transform, Load. 데이터 수집·정제·저장 파이프라인 |
