## 2. 공통 디자인 원칙

화면 정의서 1차의 "공통 디자인 원칙"을 그대로 적용합니다. 추가 사항만 명시합니다.

### 2.1 URL State 우선 원칙

검색어, 카테고리, 필터, 정렬 등 모든 탐색 상태는 **URL 쿼리 파라미터로 관리**합니다.

```
예시:
/search?q=지리산&category=mountain&region=jeonnam&sort=name_asc
```

이유:
- 새로고침/리다이렉트 시 상태 유지
- 공유 가능한 URL
- 뒤로가기 동작이 자연스러움
- 락 트리거 후 로그인 복귀 시 검색 컨텍스트 보존

### 2.2 Tier별 UI 차이

| 영역 | S0 (Free) | S3 (Member) |
|---|---|---|
| 큐레이션 섹션 제목 | "백패킹 성지" | "{nickname}님을 위한 백패킹 성지" |
| 큐레이션 섹션 제목 | "추천 캠핑장" | "{nickname}님을 위한 추천 캠핑장" |
| 카드 노출 | 동일 | 동일 |
| 검색/필터 사용 | ✅ 가능 | ✅ 가능 |
| 정렬 UI | ✅ 노출 (기능 미구현 상태 동일) | ✅ 노출 |

> 💡 Phase-1엔 추천 알고리즘이 없으므로, **라벨링만 personalization**. 실제 큐레이션 콘텐츠는 동일.

#### 3.2.6 결과 카드 (가로형)

##### 카드 레이아웃

```

│ │      │  한줄설명             │

```

##### 카드 노출 정보

| 영역 | 필드 | 처리 |
|---|---|---|
| 이미지 | `thumbnail_url` | 좌측 정사각형 또는 4:3, 이미지 부재 시 플레이스홀더 |
| 야영장명 | `title` | 1줄 ellipsis |
| 한줄설명 | `tagline` | 1줄 ellipsis (없으면 생략) |
| 위치 | `region_province` + `region_city` | "📍 전라남도 구례군" 형태 |
| 특징 태그 | `features` 상위 2개 | 칩 형태, 3개 이상일 시 "+N" 표기 |

##### 운영 상태 처리

운영중 장소만 검색 결과에 노출 (백엔드 ETL에서 폐업/휴무 제외). 카드에 운영 상태 배지 미노출.

## 4. 디자이너 추가 전달 사항

### 4.1 카드 디자인 변형 (가로형 vs 세로형)

| 위치 | 카드 형태 | 비고 |
|---|---|---|
| 홈 - 큐레이션 1 (백패킹 성지) | 세로형 (대) | 가로 스크롤, 풍경감 강조 |
| 홈 - 큐레이션 2 (추천 캠핑장) | 세로형 (소) | 2열 그리드 |
| 검색 결과 페이지 | 가로형 | 정보 밀도 높임 (디자이너 의견에 따라 변경 가능) |

### 4.2 필터 칩 vs 일반 칩 구분

| 종류 | 시각 구분 |
|---|---|
| 적용된 필터 칩 (검색결과 상단) | Primary 색상 + ✕ |
| 카드 안 특징 태그 | Neutral + # 또는 일반 텍스트 |
| 필터 모달 내 칩 | 미선택: Outline / 선택: Filled |

### 4.3 Empty State 일러스트

검색 결과 0건 시 사용. 백패킹 정서에 맞는 일러스트 (예: 빈 텐트, 빈 지도) 권장.

### 4.4 스켈레톤 디자인

| 영역 | 스켈레톤 형태 |
|---|---|
| 큐레이션 카드 | 카드 형태 회색 박스 (이미지/텍스트 라인 모방) |
| 검색 결과 카드 | 가로형 카드 모양 |
| 카테고리 칩 | 둥근 박스 |
